## SP-3 Money-to-wealth foundation (2-week track)

Audience level: `foundation`  
Duration: `2 weeks`  
Status: `active`  
Start question IDs: `U59`, `U60`, `U61`, `U64`  
Next review: `2026-04-20`

### Chapter stops

1. `3` `Where money comes from` (money-creation channels and household access map)
2. `3.5` `Cross-country transmission contrast`
3. `4` `What wealth is`
4. `5` `Why some people build wealth faster than others`
5. `6` `How wealth is built in practice`
6. `9.11.4` `Irreversibility scan`

### Checkpoints

- **Checkpoint A — Foundations clean-up**: confirm source quality for each money/wealth claim in chapters 3 and 4; record one caveat per claim.
- **Checkpoint B — Transmission realism**: map chapter-3 timing rows to one real episode or institutional report and one decision implication.
- **Checkpoint C — Channel test**: run `liquidity`, `access`, and `participation` checks and identify which channel is weakest each release window.
- **Checkpoint D — Distribution pressure check**: confirm whether gains are concentrated and whether first-time owner durability is improving.
- **Checkpoint E — Reversibility test**: apply one forced-sale/deny-borrowing stress rule before increasing leverage risk.
- **Checkpoint F — Synthesis**: define one “pause”, one “scale”, and one “watch” signal for the coming 30 days.

### Decision rhythm

- Week 1: observe and classify channels, no leverage changes.
- Week 2: act on the strongest signal only if checkpoints B, C, and E align.

### Failure modes

- If any checkpoint is unsupported by one primary/official signal, downgrade to `monitor-only`.
- If access improves without durable participation, keep risk postural assumptions conservative.
- If reversibility marker appears twice (forced-sale, deny, or borrower concentration), hold exposure and reduce optionality.

### Continuation rule

Move to the next path only after:

- both `participation` and `burden` checks improve in the same two releases,
- reversibility state is `stable`,
- and one unresolved question remains for each checkpoint.

## SP-3b Transmission and access readiness (1-week micro-path)

Audience level: `equity`  
Duration: `1 week`  
Status: `active`  
Start question IDs: `U63`, `U64`, `U65`  
Next review: `2026-04-13`

### Chapter stops

1. `3.4` `A first-mile timing check`
2. `3.5` `Cross-country transmission contrast`
3. `9` Chapter 9 (constrained transmission, entry, stress)

### Checkpoints

- **Signal check**: verify one `window 0`, one `window 1`, and one `window 2` update.
- **Borrower split check**: confirm entrant/durable owner split in at least one source family.
- **Action rule check**: ensure all leverage adjustments are tied to a verified entry-quality signal.

### Decision rhythm

- Day 1–2: map the windows and check for mismatch.
- Day 3–5: update allocation or pause rules.
- Day 6–7: choose one continuation path.

### Failure modes

- If window-2 does not improve after window-1, treat as asymmetric transmission and freeze scaling decisions.
- If entrant durability diverges from incumbent gains, remove concentration assumptions.

### Continuation rule

- Continue only if both participation durability and debt-service stress show the same directional improvement.
