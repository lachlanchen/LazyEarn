# Direct YouTube Playlist Links for Money, Wealth, Business, and Markets Courses

Updated: 2026-04-13

This is a stricter companion to `video-playlists-money-wealth.md`.
It focuses on direct YouTube playlist URLs where they could be verified, and it separates them from courses where only an official course page or channel could be confirmed.
This version also includes direct YouTube-search verification performed on 2026-04-13.

## Verification rules

- A playlist link is listed as direct only if the YouTube playlist URL was verified.
- If a playlist was verified by direct YouTube search rather than exposed on the official course page, that is stated explicitly.
- If an official course page exposes only a course page or channel, that is documented as such.
- When no canonical playlist link was visible from the official course page, this file does not invent one.
