# Side-product notes (cycle_013 round_05)

## Why this round

This round focused on practical learning artifacts that improve how the repository is used, not just how it stores notes. The priority was to reduce “information gravity” by adding a clear study route and reusable path structure.

## New artifact plan

- `knowledge/study-paths.md` is now the designated artifact for practical sequencing.
- It will support:
  - a 1-week onboarding path for new readers,
  - a 3- to 4-week production-ready path for active learners,
  - and a continuation loop linking each stop to unresolved questions.

## Design constraints

- Each path stop must include:
  - a chapter checkpoint,
  - one mechanism-focused section anchor,
  - one decision rule,
  - one likely failure mode, and
  - one continuation rule.
- Paths should avoid dense advice blocks and keep one distinction in each checkpoint (for example:
  - liquidity expansion vs allocation,
  - valuation gains vs participation gains,
  - productive leverage vs fragile leverage).
