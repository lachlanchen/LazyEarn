## Derivation Steps

Lifetime drawdown from \$1M
1. Set present age to \(21\).
2. Set terminal age to \(80\).
3. Compute the horizon as \(80-21=59\) years.
4. Convert \(59\) years to \(59\times 12=708\) months.
5. Divide \(1{,}000{,}000\) by \(708\).
6. Obtain \(\approx \$1{,}412\) per month before inflation or mistakes.

Billion from repeated million-dollar wins
1. Treat \$1B as \(1000\) retained millions.
2. Let \(r\) be the retained share of each gross \$1M.
3. Each gross \$1M contributes \(r\) retained millions.
4. Solve \(N\cdot r=1000\).
5. Get \(N=1000/r\).
6. Read Cardone’s “thousands and thousands” as the case \(r\ll 1\).

Tiny piece of the total pool
1. Set the total pool to \(T_{\$}=80\times 10^{12}\).
2. Pick a target wealth \(W\).
3. Compute \(s(W)=W/T_{\$}\).
4. Use \(s(W)\) to express the “tiny piece” framing instead of comparing to wages or neighbors.

48-unit deal arithmetic
1. Record the first two deals as single-family houses.
2. Record their lesson as limited cash flow and poor scale.
3. Record third-deal inputs \(E=350{,}000\) and \(D=1.9\times 10^6\).
4. Record third-deal output \(P\approx 3.7\times 10^6\).
5. Compute the derived multiple \(P/E\approx 10.57\).
6. Extend Cardone’s own heuristic to \(10\) similar wins: \(10\times 3.7\text{M}=37\text{M}\).

Investor funnel
1. Start with \(I=450{,}000\) interested investors.
2. Use \(N=13{,}000\) actual investors.
3. Compute \(N/I\).
4. Get \(13{,}000/450{,}000\approx 2.89\%\).
5. Flag the spoken percentage as inconsistent with the count-based calculation.

Buyer funnel and repeat purchase
1. Start with \(A=16{,}000{,}000\) audience.
2. Use \(B=154{,}000\) buyers.
3. Compute \(B/A\approx 0.9625\%\).
4. Use \(R=45{,}000\) repeat buyers.
5. Compute \(R/B\approx 29.2\%\).
6. Interpret the “close” as first paid service, not the end of the relationship.

Visible-abs comparison
1. Set \(A_{\text{abs}}=3\times 10^6\).
2. Set \(M_{\text{millionaires}}=22\times 10^6\).
3. Divide \(22\) by \(3\).
4. Get \(\approx 7.33\).
5. Use that as the arithmetic behind the “7x better chance” line.

Property underwriting identity
1. Define the financed party as \(\mathrm{LLC}_{48}\).
2. Separate the asset-holding entity from the individual speaker.
3. Tie the loan conceptually to asset income and asset structure.
4. Use this to explain the lecture’s “assets, not credit score” claim.

## Notation Choices

- Use \(T_{\$}\) for the total dollar pool throughout; do not switch between “money supply,” “circulation,” and “cash pool” without definition.
- Use \(W\) for desired wealth and \(s(W)\) for its share of the total pool.
- Use arrows \(\to\) for process, funnel, and state change; reserve \(=\) for explicit identities and \(\approx\) for derived estimates.
- Use uppercase letters for stocks and counts: \(A,I,N,B,R,E,D,P,L,V\).
- Use lowercase \(c\) for conversion rates: \(c_{\text{invest}},c_{\text{buy}},c_{\text{repeat}}\).
- Use \(\mathrm{CF}\) for cash flow.
- Do not introduce \(\mathrm{NOI}\), cap rate, IRR, DSCR, or other real-estate notation not stated in the lecture.
- Use \(\mathrm{LLC}_{48}\) for the borrowing entity on the 48-unit example.
- Use \(r\) for retained fraction after leakage from gross earnings.
- Write economic states in text mode inside math: \(\text{rich}\), \(\text{wealthy}\).
- Keep dollar figures as explicit numerals in the working bank; convert to prose-friendly “million/billion/trillion” only in the written chapter.
- Treat “free” and “paid” as operational shares \(f_{\text{free}}\) and \(f_{\text{paid}}\), not as metaphysical categories.
