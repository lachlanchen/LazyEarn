## Derivation Steps

1. Exit-ownership fraction in the Solidcore case
   1. Read personal equity at sale as about \(\$90\) million.
   2. Read company value as a little over \(\$300\) million.
   3. Form the ratio \(f_{\text{equity}} = E_{\text{exit}}/V_{\text{company}}\).
   4. Using \(\$300\) million as a rough denominator gives about \(0.30\).
   5. State cautiously that the true ratio is likely slightly below \(0.30\) if the denominator is indeed above \(\$300\) million.

2. Solidcore capital multiple
   1. Take the transcript-backed start \(I_0=\$175{,}000\).
   2. Take the transcript-backed endpoint \(V_{10}\approx \$100\,\text{million}\).
   3. Compute \(M = V_{10}/I_0\).
   4. Obtain \(M \approx 571.4\).

3. Equivalent annualized growth for the Solidcore story
   1. Treat the story as a start-end transformation over \(10\) years.
   2. Solve \(V_{10}=I_0(1+r_{\text{eq}})^{10}\).
   3. Rearrange to \(r_{\text{eq}}=(V_{10}/I_0)^{1/10}-1\).
   4. Substitute the start and end values.
   5. Obtain \(r_{\text{eq}} \approx 0.887\), or about \(88.7\%\) per year.
   6. Mark this as a lump-sum equivalent rate, not an audited cash-flow IRR.

4. Weekly volleyball load
   1. Read \(h_{\text{volleyball}} \approx 2\text{--}3\) hours per day.
   2. Read \(d_{\text{volleyball}} = 5\) days per week.
   3. Multiply \(H_{\text{volleyball}} = h_{\text{volleyball}} d_{\text{volleyball}}\).
   4. Obtain \(H_{\text{volleyball}} \approx 10\text{--}15\) hours per week.

5. Translating “nine figures”
   1. Read the phrase “nine figures in one year.”
   2. Interpret nine figures as at least \(\$100{,}000{,}000\).
   3. Use an inequality, not an equality:
      \[
      Y_{\text{hair}} \ge \$100\,\text{million}.
      \]

6. Oil-case leverage logic
   1. Borrow capital.
   2. Spread it across uses rather than deploying it as one indivisible block.
   3. Multiply returns through that spread.
   4. Repay before or as the capital begins producing.
   5. Keep this as a state sequence, not a literal algebraic leverage model.
