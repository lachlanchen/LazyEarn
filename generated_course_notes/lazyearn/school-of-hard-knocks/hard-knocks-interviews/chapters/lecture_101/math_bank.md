## Derivation Steps
1. Gross-to-net month reconstruction:
   1. Take the cited month values \(G_m=5.0\,\text{M}\) and \(N_m=3.9\,\text{M}\).
   2. Form the ratio \(m_{\text{net}}=N_m/G_m\).
   3. Compute \(m_{\text{net}}\approx 0.78\).
   4. Read this only as a margin estimate for that cited period.

2. Solar revenue doubling estimate:
   1. Take the stated prior-year revenue \(R_{\text{solar},y}=149\,\text{M}\).
   2. Use the spoken claim “double that this year.”
   3. Compute \(2\cdot 149=298\).
   4. Treat the host’s “about \(300\,\text{M}\)” as rounded confirmation.

3. Branding markup reconstruction:
   1. Take the example cost \(c_{\text{shoe}}=20\).
   2. Take the tagged price range \(p_{\text{tag}}\in[800,900]\).
   3. Compute the multiple \(p_{\text{tag}}/c_{\text{shoe}}\in[40,45]\).
   4. Use the result only to quantify the speaker’s branding / scarcity claim.

4. Seven-to-eight-to-nine figure ladder:
   1. Record the seven-figure ingredients as idea, sales, and marketing.
   2. Add team to express the eight-figure transition.
   3. Replace informal hustle logic with product, marketing, sales, team, and systems for the nine-figure stage.
   4. Treat this as a stage model, not a theorem.

5. SOP transfer logic:
   1. Start from the claim that every recurring function should be documented.
   2. If a function is documented, another colleague can read and execute it.
   3. If execution survives the owner’s absence, dependence shifts from CEO to system.
   4. This is the lecture’s main mechanism for the eight-to-nine figure jump.

6. “Follow the graph” operational chain:
   1. Track revenue as the result of sales-and-marketing performance.
   2. Track impressions, content performance, and algorithmic pickup in social media.
   3. Use these metrics to decide where to double down.
   4. The claimed growth effect comes from decision quality, not from vague hustle alone.

7. Revenue attachment logic:
   1. Marketing controls \(L\), the incoming lead flow.
   2. Lead flow gives sales something to work on.
   3. Sales closes revenue \(R\).
   4. Therefore bargaining power rises when one is attached upstream to revenue generation.

8. Compounding reconstruction:

   2. Let returns compound at rate \(r\) over \(n\) years.
   3. Use \(FV_n=a\frac{(1+r)^n-1}{r}\) for the accumulated value.
   4. Keep this generic; the lecture gives no specific \(a\), \(r\), or \(n\).

9. Downturn resilience model:

   2. Record assets usable as collateral as the second buffer.
   3. Record portable sales / marketing skill as the third buffer.
   4. Read resilience as a bundle of buffers, not a single scalar law.
