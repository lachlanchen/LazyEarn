## Derivation Steps

1. Wealth accumulation from surplus
   1. Begin with period income \(I_t\).
   2. Subtract expenditures \(E_t\).
   3. Define surplus as \(S_t = I_t - E_t\).
   4. Treat positive \(S_t\) as the amount available for accumulation.
   5. Use this only as a standard reconstruction of the lecture’s spending-habits logic.

2. Leakage version of the energy/spending argument
   1. Split expenditure into necessary spending and leakage spending.
   2. Write \(E_t = E_{\text{necessary},t} + E_{\text{leakage},t}\).
   3. Then \(S_{\text{net},t} = I_t - E_{\text{necessary},t} - E_{\text{leakage},t}\).
   4. Interpret “drink/party/girlfriend/sex” rhetoric as examples of leakage, cautiously.
   5. Conclude: larger leakage lowers investable surplus.

3. Compounding reconstruction from the Buffett reference
   1. Start with investable wealth \(W_0\).
   2. Apply a growth rate \(r\) over one period.
   3. Obtain \(W_1 = W_0(1+r)\).
   4. Iterate to \(W_t = W_0(1+r)^t\).
   5. Use this only to formalize “not tomorrow, over that lifespan.”

4. Exit-rule reconstruction from the 30% benchmark
   1. Let \(P_0\) be entry price/value.
   2. Let \(P_t\) be current price/value.
   3. Compute return \(\dfrac{P_t - P_0}{P_0}\).
   4. Compare to benchmark \(0.30\).
   5. If the benchmark is reached, sell.
   6. Mark exact phrasing as uncertain because transcript says “pull it 30%.”

5. Survival-floor decision structure
   1. Set required monthly inflow \(C_{\text{monthly floor}} \approx \$2{,}000\).
   2. Compare available career options by whether they can satisfy that floor.
   3. If an option meets the floor, it preserves the ability to remain in New York City.
   4. The real-estate license is selected under that constraint.
   5. Use as a decision-under-cash-constraint reconstruction, not a spoken equation.

6. Scale separation
   1. List each numerical claim by type: income, revenue, sales volume, asset price.
   2. Do not merge them into one “money made” variable.
   3. Keep \(Y\)-type objects for earnings/revenue and \(V\)-type objects for transaction volume.
   4. State explicitly that \$4.5B sales volume is not the same as personal income.
   5. Use this separation whenever the chapter compares interview claims.

7. Role-ranking comparison from Gary Vee
   1. Identify the claim: elite non-founder roles in giant firms can out-earn most founders.
   2. Treat “99.99999999%” as rhetorical emphasis rather than a measured probability.
   3. Preserve the inequality only verbally unless external verification is added.
   4. Use it to motivate a role-fit argument, not a statistical theorem.
