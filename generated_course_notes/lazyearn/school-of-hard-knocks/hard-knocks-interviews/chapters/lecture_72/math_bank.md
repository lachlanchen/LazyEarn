## Derivation Steps
Goal-attainment ratio
1. Set the stated target to \(G_{10} = \$1\) billion.
2. Set the realized outcome to \(R_{10} \approx \$0.8\) billion.
3. Form the ratio \(\dfrac{R_{10}}{G_{10}}\).
4. Read the result only as a framing measure of goal attainment, not as a full business evaluation.

Profitability filter
1. Start with many simultaneous activities.
2. Refuse to stop at gross movement or visible status signals.
3. Ask for documentary quantities: P\&L, net, EBITDA.
4. Identify the line with real positive economics.
5. Concentrate effort there before diversifying.

Reinvestment-to-equity loop
1. Operating cash enters the business.
2. Cash is returned to the business rather than fully paid out.
3. Capacity, infrastructure, or client base expands.
4. Equity value accumulates.
5. Later payout or exit value becomes larger than early personal consumption would have produced.

Three-legged stool decision rule
1. Take a proposed decision \(D\).
2. Test whether \(D\) is good for the client.
3. Test whether \(D\) is good for the agent/employee/partner.
4. Test whether \(D\) harms the company.
5. Reject \(D\) if any leg fails.
6. Accept \(D\) only if all three legs hold.

Leverage rule
1. Identify the borrowing cost \(r_{\text{borrow}}\).
2. Estimate the attainable deployment return \(r_{\text{deploy}}\).
3. Compare return to cost.
4. Borrow only if \(r_{\text{deploy}} > r_{\text{borrow}}\) by a meaningful margin.
5. Treat cheap money as valuable only because it can be deployed profitably.

Hard-money hurdle
1. Start with principal \(L_{\text{hard}} = \$200{,}000\).
2. Add stated interest \(r_{\text{hard}} = 12\%\).
3. Add quoted points / fees every six months.
4. Treat total cost as materially above the nominal interest rate alone.
5. Use this financing only if project returns clear that higher hurdle.

“Never lose / don’t go backwards” compounding intuition
1. Prefer avoiding negative years to chasing spectacular but unstable swings.
2. Accept modest positive years if capital base stays intact.
3. Repeat over multiple periods.
4. Let the base compound forward without major drawdown.
5. Use this as the operational meaning of his “don’t go backwards” line.

Control-set procedure
1. Write down the full problem set.
2. Partition it into \(\mathcal{C}\) and \(\mathcal{N}\).
3. Ignore \(\mathcal{N}\) for immediate action.
4. Rank and attack items in \(\mathcal{C}\).
5. Recompute the partition after each action.

Sales-equalizer mechanism
1. Start with low capital, weak network, or low formal business training.
2. Enter sales because entry cost is low relative to ownership-heavy businesses.
3. Increase \(W\) through repeated calls, repetition, and exposure.
4. Let higher \(W\) build \(S\).
5. Let stronger \(S\) improve sales effectiveness.
6. Add recruiting and training to move from individual sales to distribution and scale.
