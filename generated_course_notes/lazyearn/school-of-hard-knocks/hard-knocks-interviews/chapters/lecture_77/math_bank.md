## Derivation Steps
Liquidity fragility
1. Start with \(B_{\text{avail}} = \$78\).
2. Let pending obligations be \(C_{\text{out}}\).
3. Compute \(B_{\text{post}} = B_{\text{avail}} - C_{\text{out}}\).
4. If \(C_{\text{out}} > \$78\), then \(B_{\text{post}} < 0\).
5. Therefore near-zero liquidity creates immediate operational fragility even before large losses occur.

Advice-filter rule
1. Fix a domain \(d\).
2. Compare the advisor’s realized outcome \(O_d(i)\) with the decision-maker’s current level or with weaker alternatives.
3. Reject advice from a person whose outcome is not demonstrably strong in that same domain.
4. Therefore advice is filtered by domain-specific performance, not by generic confidence.

Competitive-market argument
1. Observe that an industry is crowded.
2. Interpret crowding as evidence of market size rather than proof of impossibility.
3. Add the claim \(p(R>\$10\,\text{M}) < 0.01\).
4. Conclude that participation is common but upper-tail execution is rare.
5. Therefore a newcomer can still win by entering the thin high-effort tail.

Sales-close argument
1. Begin the conversation as if the counterpart is already moving toward client status.
2. Use speech that presupposes the relationship rather than begging for it.
3. Add rapport and humor to increase liking.
4. Use the speaker’s heuristic that people resist less when they like the seller.
5. Therefore assumed close plus rapport is presented as a higher-probability closing posture.

Walk-away leverage
1. Neediness lowers negotiating strength.
2. A credible outside option raises the ability to refuse bad terms.
3. The speaker adds the heuristic “the first person to speak loses.”
4. He then substitutes proof of value: consistency, case studies, cadence.
5. Therefore leverage is built by demonstrated value and genuine willingness to walk.

Rebuild-from-zero logic
1. Lower the personal consumption floor to a Spartan baseline.
2. Reduce fear of downside by accepting harsh fallback conditions.
3. Preserve willingness to work unpleasant jobs if necessary.
4. This increases persistence and bargaining patience.
5. Therefore resilience strengthens both survival odds and negotiating posture.
