2. Set \(P = \$64{,}000\).
3. Compute \(d = P/F = 0.04\).
4. Compute \(\delta = 1 - d = 0.96\).

Boom-bust investing rule
1. In a boom, participants behave as if the boom will never end.
2. In a bust, participants behave as if recovery will never come.
3. Preserve memory of the opposite phase when current sentiment becomes extreme.
4. Buy in the bust when pessimism appears overembedded in price.
5. In the boom, do not extrapolate current conditions forever.

Backward-planning rule
1. Choose a rough long-horizon endpoint \(T_{30}\).
2. Ask what intermediate states must exist for \(T_{30}\) to be reachable.
3. Infer what present actions \(A_0\) make those intermediate states possible.
4. Let current action be constrained by the end state rather than by drift.
5. Treat this as a planning heuristic, not an optimization proof.

4. Treat failure in any one of the three as a threat to survival.
