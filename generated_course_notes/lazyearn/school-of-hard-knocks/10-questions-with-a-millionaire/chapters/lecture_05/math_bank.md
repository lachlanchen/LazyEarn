## Derivation Steps

1. **Delegation capacity**
   1. Start with \(N = 155\) locations.
   2. One person cannot personally be present in \(155\) places.
   3. Therefore personal capacity \(C_{\text{one person}}\) is less than location demand.
   4. Add delegated operators with capacities \(c_i\).
   5. Scale is possible only if \(\sum_i c_i \geq N\).

2. **Negotiation low-anchor loss**
   1. Counterparty budget is given as \(B = \$200\text{M}\).
   2. Low opening ask is \(a_0 = \$50\text{M}\).
   3. Potential value left unasked is \(B-a_0\).
   4. Compute \(200-50=150\).
   5. Result: low anchor can cost \(\$150\text{M}\) in the example.

3. **75/25 savings rule**
   1. Let income be \(I\).
   2. Save \(75\%\): \(S=0.75I\).
   3. Spend or enjoy \(25\%\): \(F=0.25I\).
   4. Check total: \(S+F=I\).

4. **Annuity preservation model**
   1. Start with lump wealth \(W_0\).
   2. Avoid treating the whole amount as immediately spendable.
   3. Convert \(W_0\) into scheduled payments \(P_t\).
   4. Use this only as standard reconstruction; Shaq only gives the word “annuity.”

5. **Copying as skill synthesis**
   1. Observe performer \(M_j\).
   2. Extract behavior or discipline \(s_j\).
   3. Combine multiple \(s_j\) into personal operating style.
   4. Do not overformalize; this is a metaphorical mechanism, not a literal equation.
