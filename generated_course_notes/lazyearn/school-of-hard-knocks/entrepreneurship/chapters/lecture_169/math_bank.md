## Derivation Steps
1. Ownership dilution mechanism
   1. Start with ownership fraction \(f_i = s_i/S\).
   2. A transaction changes the cap table or share count.
   3. Write the new fraction as \(f_i' = s_i'/S'\).
   4. If the holder does not gain proportionate shares while total shares rise, then \(S' > S\) and \(f_i' < f_i\).
   5. This is the cleanest formal version of the lecture’s warning about Saverin’s reduced ownership.

2. Execution-over-idea logic
   1. Begin with an idea \(I\).
   2. Without execution capacity \(E\), the idea remains unrealized.
   3. Realization requires skill or a team able to build.
   4. Hence the lecture’s practical claim is not “idea alone,” but “idea plus execution” leading to outcome \(O\).

3. Persistence logic from FaceMash to Facebook
   1. Initial attempt fails or creates trouble.
   2. The failed attempt still generates learning, direction, or momentum.
   3. The next venture inherits that momentum.
   4. Obstacles then shift from invention to growth: awareness, users, funding, hiring, workload.
   5. Persistence is therefore not a slogan but endurance across successive operating constraints.

4. “One door closes” redirection logic
   1. A desired path closes.
   2. The immediate state is disappointment or perceived failure.
   3. The lecturer reframes this as redirection rather than termination.
   4. The next opportunity may be better aligned than the first.
   5. Use this only as a conceptual schema, not a quantitative model.
