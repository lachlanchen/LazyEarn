## Definitions And Objects

- `Buyer resistance`: the transcript-backed premise that people dislike being sold to.

- `Buyer agency`: the transcript-backed counterpoint that people still like to buy.

- `Solution selling`: the speaker’s name for a question-led method that starts with the client’s need rather than the seller’s demo.

- `True need` \(N\): what the seller is trying to understand before presenting anything.

- `Pain points` \(P\): the client’s concrete problems or frictions that should guide the conversation.

- `Solution` \(S\): the product, service, or proposal only worth presenting if it can help solve \(N\) or \(P\).

- `Fit relation` \(\operatorname{Fit}(S,N)\): optional reconstructed notation for whether the solution addresses the need.

- `Demo-first selling`: the negative case where the seller shows everything and waits for the buyer to react.

## Derivation Steps

1. Start with the constraint: buyers resist being sold to.

2. Add the counterpoint: buyers still want to buy when the purchase serves them.

3. Therefore, the seller should not begin with pressure or a full product demo.

4. The seller should begin with questions.

5. Questions reveal the client’s true need.

6. The seller then checks whether the offered solution can help with that need.

7. If there is fit, the conversation becomes mutual problem-solving.

8. If there is no diagnosis, the seller falls back into random demo-first selling.
