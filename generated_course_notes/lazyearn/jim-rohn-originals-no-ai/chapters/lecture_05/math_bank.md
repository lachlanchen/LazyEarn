## Definitions And Objects
- \(W\): wages; use for the lecture’s “make a living” channel.
- \(P\): profits; use for the lecture’s “make a fortune” channel.
- \(W_{\mathrm{ft}}\): full-time wage income.
- \(P_{\mathrm{pt}}\): part-time profit income.
- \(\Delta I\): incremental monthly income; use only for the “extra thousand a month” threshold.
- \(W\) and \(S\) in the sailboat model: common wind and adjustable sail-setting; if ambiguity is a problem, rename wind to \(\mathcal{W}\).
- \(A\): arrival / destination / outcome in the sailboat shorthand.
- \(R\): conversion ratio / average outcome per attempt.
- \(n\): number of conversations / attempts.
- \(s\): number of positive outcomes / successes.
- \(N_{\mathrm{served}}\): number of people directly and indirectly served.
- \(Y\): payoff / income / greatness output; keep schematic, not econometric.
- “Seed”: the offered story / opportunity / invitation.
- “Birds”: external discouragement before engagement.
- “Hot weather”: early dropout after initial growth.
- “Thorns”: small distractions choking growth.
- “Good ground”: receptive cases that produce durable outcomes.
- \(30\%,60\%,100\%\): heterogeneous output levels among good-ground cases.
- “Deserve” vs “need”: response criterion in the sponsor section; not algebraic, but a rule selecting who receives time and effort.

## Derivation Steps
Profit-to-fortune ladder
1. Start with the verbal inequality: wages support living; profits support fortune.
2. Introduce the part-time mechanism: profits can begin before leaving the job.
3. First target: set part-time profits equal to full-time wages, \(P_{\mathrm{pt}} = W_{\mathrm{ft}}\).
4. Second target: raise part-time profits to double full-time wages, \(P_{\mathrm{pt}} = 2W_{\mathrm{ft}}\).
5. Infer the narrative consequence: once \(P_{\mathrm{pt}}\) visibly changes lifestyle, the invitation becomes more compelling.
6. Infer the recruiting consequence: lifestyle evidence, not abstract promise, drives attention.

Wind-and-sail causal decomposition
1. Hold the external wind fixed across people.
2. Deny that outcome differences are primarily explained by external conditions.
3. Move the controllable variable to sail-setting, discipline, and philosophy.
4. Represent the outcome schematically as \(A = A(S;W)\).
5. Use repeated seasons / history examples to argue that \(W\) varies in pattern but is not individually negotiable.
6. Conclude that change in arrival comes from better setting of the sail, not waiting for better wind.

Law-of-averages competition
1. Define the average outcome rate by repeated action: \(R = s/n\).
2. Start with the novice case \(R = 1/10\).
3. Compare against a skilled case \(R = 9/10\).
4. Keep the skilled person at \(n=10\), giving \(s=9\).
5. Scale the novice to \(n=100\), giving \(s=10\).
6. Conclude that volume can dominate skill over a fixed contest window.
7. Convert the slogan into the rule: make up in numbers what is lacking in skill.

Law-of-averages improvement
1. Begin with \(R = 1/10\).
2. Repeat the action enough times to stabilize the ratio.
3. Improve skill through repetition rather than through prior perfection.
4. Raise the working ratio stepwise to \(2/10\), then \(3/10\).
5. Use baseball \(0.300\) as the normalizing analogy.
6. Conclude that elite payoff does not require perfect success.

Sower filter model
1. Start with an input stream of “seed,” meaning invitations, stories, or opportunities.
2. First loss channel: birds remove some before they take root.
3. Second loss channel: shallow ground allows initial growth but collapses under heat.
4. Third loss channel: thorns choke growth through distraction.
5. Remaining seed reaches good ground.
6. Good ground is still heterogeneous: \(30\%,60\%,100\%\).
7. Therefore persistence requires accepting structured loss before output.
8. Therefore the practical rule is not “eliminate all loss” but “keep sowing.”

Disappointment discipline
1. Observe that not all losses are caused by speaker error.
2. Separate avoidable mistakes from normal-course failures.
3. For normal-course failures, reject endless causal inquiry.
4. Replace reaction with the rule “discipline your disappointment.”
5. Resume the input process rather than chasing each failure.

Service scaling
1. Pose the greatness question.
2. Answer it with service-to-many rather than self-protection.
3. Let the number served be the scaling variable \(N_{\mathrm{served}}\).
4. Let income / influence / greatness be the output \(Y\).
5. State only the monotone relation \(Y \uparrow\) as \(N_{\mathrm{served}} \uparrow\).
6. Avoid formalizing the dependence further; the lecture stays qualitative here.

Deserve-response rule
1. Reject “need” as the selection criterion.
2. Replace it with movement, planting, response, and effort.
3. Encode the sponsor asymmetry as escalating response: one step gets two back; two steps get five back.
4. Encode nonresponse as \(0 \mapsto 0\).
5. Use this as a practical allocation rule for attention, not as a theorem.

## Notation Choices
- Use \(W\) for wages and \(P\) for profits throughout; do not switch to salary, revenue, or cash flow.
- Use subscripts `ft` and `pt` for full-time and part-time: \(W_{\mathrm{ft}}, P_{\mathrm{pt}}\).
- Keep all symbolic lines that were not spoken as clearly editorial shorthand in the surrounding prose.
- Reserve \(R = s/n\) for the law of averages; do not introduce probability notation \(p\) unless necessary.
- Use \(A\) for “arrival” in the sailboat model and \(S\) for sail-setting; if conflict with success count \(s\) is awkward, keep success count as lowercase \(s\) and sail-setting as uppercase \(S\).
- Use percentages exactly as the lecture uses them for the sower outputs: \(30\%, 60\%, 100\%\), not decimal fractions.
- Treat “seed,” “birds,” “hot weather,” “thorns,” and “good ground” as named objects in a filter model, not as hidden variables in a formal stochastic system.
- Use \(N_{\mathrm{served}}\) and \(Y\) only as schematic variables for the service principle; do not imply a fitted formula.
- Keep “deserve” and “need” in roman text rather than symbolic operators.
- Use `sail`, not `sale`, in all mathematical shorthand tied to the wind metaphor.
