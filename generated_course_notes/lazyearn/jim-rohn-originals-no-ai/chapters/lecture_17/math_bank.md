## Definitions And Objects
- Personal development: the inner process of becoming more; the lecture’s master variable behind changed outcomes.
- Marketplace: the external evaluative setting in which value is tested and paid for.
- Reality: Rohn’s explicit gloss for the marketplace.
- Time: the medium in which value is delivered; necessary but not itself the object of payment.
- Value: the operative economic quantity; what is brought to the marketplace and what pay tracks.
- Pay / money / income: the countable economic output used as the lecture’s first diagnostic.
- Same time: the condition held fixed when asking whether higher value can yield higher pay.
- Starting rung: the bottom wage level, around \(\$4/\text{hour}\).
- Ladder: the lecture’s preferred structural metaphor for economic advancement.
- Climb: upward movement generated by added value, not by mere complaint or demand.
- Marketplace value: the specific kind of value rewarded economically.
- Human value: moral, communal, religious, or familial value; explicitly distinguished from marketplace value.
- Demand: strike, complaint, or waiting for a raise as a false causal strategy for getting rich.
- Opportunity call: the later narrative proof that value attracts higher-stakes invitations.
- Self-work: working on philosophy, attitude, personality, language, communication, and abilities.

## Derivation Steps
### Opening Change Formula
1. Start with the claim that outer circumstances need not be changed directly.
2. Move the causal burden to the inside.
3. Reformulate inside change as becoming more.
4. Conclude that having more follows from becoming more.

### Value Versus Time
1. Introduce money as the first countable test case.
2. State that pay comes from bringing value to the marketplace.
3. Note that time is required to bring value.
4. Deny that time itself is what is purchased.
5. Replace “paid for hours” with “paid for value placed into time.”
6. Conclude that value, not time alone, is the meaningful economic variable.

### Same-Time Multiplication Question
1. Hold time fixed.
2. Ask whether value can be doubled.
3. Ask whether doubled value yields doubled money in the same time.
4. Repeat the question for tripling.
5. Answer with an emphatic yes.
6. Summarize: more money in the same time comes from becoming more valuable.

### Ladder Model
1. Introduce America as a ladder rather than a bed.
2. Place the starting rung at about \(\$4/\text{hour}\).
3. Reject fixation on whether the start “should be five.”
4. Reinterpret the problem as one of climbing, not permanent occupancy of the bottom rung.
5. Make increased value the mechanism of upward movement.
6. Extend the ladder upward to very large incomes.

### Marketplace Distinction
1. Ask why some people receive only low pay.
2. Answer: low marketplace value.
3. Separate marketplace value from other kinds of value.
4. State the hard rule: marketplace reality rewards marketplace value.
5. Infer that more money requires more marketplace value, not moral complaint.

### Demand Versus Climb
1. Raise the proposal of strike or demand for more money.
2. Reject it as a route to riches.
3. Raise the alternative of waiting for a raise.
4. Reject waiting as slower and weaker than climbing.
5. Replace both with the rule: become more valuable.

### Opportunity Proof
1. Present the phone call worth millions.
2. Ask why that call came to him.
3. Answer: he had become valuable.
4. Generalize from anecdote to mechanism: value attracts opportunity.
5. Reconnect to the opening theme of self-change.

### Shoaff Formula
1. State the secret: work harder on yourself than on your job.
2. Contrast job-work with self-work.
3. Infer: hard job-work yields a living.
4. Infer: hard self-work yields a fortune.
5. Expand self-work into concrete domains of inner development.

## Notation Choices
- Prefer text-heavy display math over compressed symbolic algebra.
- Use \(\text{Value}\), \(\text{time}\), \(\text{Pay}\), \(\text{Marketplace}\), \(\text{Reality}\) rather than single letters when space allows.
- If compact symbols are needed:
  - \(V\): marketplace value
  - \(T\): time
  - \(P\): pay / income
  - \(r\): ladder rung or wage level
- Use \(\Longleftarrow\) for strategic or causal dependence in the lecture’s preferred direction, e.g. outcome from self-change.
- Use \(\Longrightarrow\) for operational consequence, e.g. more value implies more money.
- Use \(\to\) for ladder movement or sequence, e.g. \(\$4 \to \$5 \to \cdots\).
- Use \(\propto\) sparingly and only for the cleaned relation between pay and value.
- Use \(\neq\) for the corrected contrast \(\text{Pay} \neq \text{Time alone}\).
- Keep money in explicit dollar notation: \(\$4/\text{hour}\), \(52\,\text{million dollars/year}\).
- Keep \(\text{Marketplace}=\text{Reality}\) in words because it is an explicit lecture gloss, not a formal definition from economics.
- Avoid introducing formal supply-demand notation, utility notation, marginal notation, or production functions.
