# Yale Financial Markets Publication

![Yale Financial Markets cover](cover-art.png)

A published shelf for the completed `Financial Markets` companion notes based on Robert J. Shiller's Yale lectures.

This folder exists at the repo root on purpose. It is the direct publication surface for the course edition, separate from the internal generation tree in `generated_course_notes/`.

## What is here

- [yale-financial-markets.pdf](yale-financial-markets.pdf): the complete course book in one file
- [lecture_01.pdf](lecture_01.pdf) to [lecture_23.pdf](lecture_23.pdf): one PDF per lecture
- [cover-art.png](cover-art.png): the current publication cover art

## Quick links

## Publication note

These notes are a curated course companion, not an official Yale edition. The underlying lecture credit remains with Robert J. Shiller. The note curation, PDF assembly, cover publishing, and repository distribution are maintained by LazyingArt LLC through `Video2Book` and `LazyEarn`.
