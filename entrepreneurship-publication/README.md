# Entrepreneurship

Published LazyEarn editions of the completed School of Hard Knocks entrepreneurship sequence.

This shelf contains two separate books built from the same unique interview corpus:

- `Entrepreneurship` keeps the lecture-by-lecture structure as a practical field book on sales, offers, leverage, capital, distribution, operations, and founder judgment.
- `How You Build a Business?` reorganizes the same material into a nonlinear dynamic book focused on recurring business mechanisms and operating systems.
